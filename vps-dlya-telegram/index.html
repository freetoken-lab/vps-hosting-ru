Настройка

Как настроить VPS для Telegram: пошаговое руководство

После получения VPS выполните следующие шаги, чтобы развернуть бота или прокси для Telegram. Руководство рассчитано на Ubuntu 22.04 LTS — рекомендуемую ОС для большинства задач.

  1. Подключитесь к серверу и обновите систему Используйте SSH для подключения, затем обновите пакеты:
    $ ssh root@ВАШ_IP && apt update && apt upgrade -y
    После обновления перезагрузите сервер: reboot
  2. Установите Python и зависимости для бота Большинство современных Telegram-ботов написаны на Python:
    $ apt install python3 python3-pip python3-venv -y
    $ pip3 install aiogram # или python-telegram-bot
    Для Node.js-ботов: apt install nodejs npm -y
  3. Загрузите код бота и настройте переменные окружения Загрузите код через Git или SFTP, создайте файл с токеном бота:
    $ git clone https://github.com/ваш-репозиторий/bot.git && cd bot
    $ echo "BOT_TOKEN=ваш_токен" > .env
    Никогда не храните токен прямо в коде — только в переменных окружения или файле .env, добавленном в .gitignore.
  4. Запустите бота как системный сервис Используйте systemd или screen для запуска бота в фоне с автозапуском после перезагрузки:
    $ nano /etc/systemd/system/mybot.service
    Вставьте в файл описание сервиса, затем:
    $ systemctl enable mybot && systemctl start mybot
  5. Настройте MTProto-прокси или SOCKS5 (опционально) Для прокси для Telegram на VPS — установка MTProto-сервера одной командой:
    $ curl -fsSL https://github.com/alexbers/mtprotoproxy/releases/latest/download/install.sh | bash
    После установки вы получите ссылку вида tg://proxy?server=IP&port=443&secret=... — добавьте её в настройки Telegram на мобильном или ПК.
  6. Настройте базовую безопасность сервера Минимальный набор для защиты от автоматических атак:
    $ apt install ufw fail2ban -y
    $ ufw allow 2222/tcp && ufw allow 443/tcp && ufw enable
    Смените стандартный порт SSH с 22 на 2222 в файле /etc/ssh/sshd_config.
